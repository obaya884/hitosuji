- 版数: 0.1（ドラフト）
- フェーズ: Phase 1（MVP）
- 対応要求: F-105（セクション定義）, F-401（モード）, F-402（プロジェクト）
- 上位文書: [要件定義書](../要件定義書.md)

---

## 1. 画面の役割

セクション・モード・プロジェクトの3マスタを管理する。タブ切替で1画面に集約する。利用頻度は低く（初期設定時と、プロジェクト追加時程度）、シンプルなCRUDに徹する。**この画面は N-01（楽観的更新）の対象外**とし、保存の完了を待って一覧へ反映する（即UI反映＋ロールバックは行わない）。

## 3. タブ別仕様

### 3.1 セクション

| 列 | 仕様 |
|---|---|
| 名前 | テキスト（50文字以内） |
| 開始 | `HH:MM`。**終了時刻は入力しない**（次セクションの開始から自動導出され、`06:00–09:00` のように枠として表示のみ） |
| 操作 | 編集 / アーカイブ |

- 並び順は `start_time` 昇順で自動決定（手動の並び替えは提供しない。時刻を編集すれば並びが追従する）
- 有効なセクションは常に24時間を隙間・重複なく敷き詰める（データモデル定義書 §3.1）。開始時刻を編集すると、自身と前のセクションの枠が連動して変わる

**バリデーション**: 有効セクション間の start_time 重複はエラー。有効なセクションは最低1件必要（全件アーカイブ不可）。重複・隙間のチェックは構造上不要。

**初期データ（要件定義書 §8-2 で決定済み）**: 朝 6:00 / 午前 9:00 / 午後 12:00 / 夜 18:00 / 深夜 0:00

### 3.2 モード

| 列 | 仕様 |
|---|---|
| 色 | カラーバー表示。編集時はプリセット13色（12色＋グレー）から選択（自由入力は設けない。N-05）。グレーは初期データ「休憩」で使う |
| 名前 | テキスト（50文字以内） |
| 操作 | 編集 / アーカイブ |

### 3.3 プロジェクト

| 列 | 仕様 |
|---|---|
| 名前 | テキスト（50文字以内） |
| 操作 | 編集 / アーカイブ |

## 4. 共通仕様

| 項目 | 仕様 |
|---|---|
| 並び順 | 手動の並び替えは提供しない。セクションは start_time 昇順、モード・プロジェクトは name 昇順（自然順ソート）。並びを制御したい場合は `01.仕事` のように名前へ接頭辞を付ける運用（S-01 等の選択肢・表示にもそのまま反映される） |
| アーカイブ | 物理削除は提供しない。アーカイブ済みは一覧下部に折りたたみ表示し、復元可能。過去タスク・ルーチンからの参照は保たれる |
| アーカイブ済みマスタの扱い | S-01/S-02 の選択肢には表示しない。参照中のタスク表示には従来どおり使われる |
| 名前変更の影響 | 参照している全タスク・ルーチンの表示に即時反映される（IDで参照しているため） |
| 削除的な整理が必要な場合 | 誤作成直後のみ想定。参照0件のマスタに限り物理削除ボタンを表示する |
