- 版数: 0.1（ドラフト）
- フェーズ: Phase 1（MVP）
- 対応要求: F-301, F-302, F-303（Phase 3: F-304, F-305）
- 上位文書: [要件定義書](../要件定義書.md)

## 1. 画面の役割

ルーチン（デイリーリストへ自動展開されるタスクの雛形）の一覧・作成・編集・有効/無効切替を行う。利用頻度は低い（週1回程度の見直し）ため、S-01ほどの操作最適化は行わずシンプルなCRUDに徹する。

## 2. レイアウト

```
┌──────────────────────────────────────────────────────────────┐
│ [デイリー] [ルーチン] [マスタ] [レビュー]                       │
├──────────────────────────────────────────────────────────────┤
│ ルーチン一覧                                  [＋ 新規ルーチン] │
├──────────────────────────────────────────────────────────────┤
│ 名前         モード  プロジェクト 見積 繰り返し   開始想定    有効     │
│ 朝食         生活              0:20 毎日       06:30 (朝)   [✓] [編集] │
│ 週次レビュー  仕事    改善       0:30 週次(土)   10:00 (午前) [✓] [編集] │
│ 経費精算     仕事    経理       0:15 月次(25日) 13:30 (午後) [ ] [編集] │
└──────────────────────────────────────────────────────────────┘
```

## 3. 表示要素（一覧）

列は左から **名前 / モード / プロジェクト / 見積 / 繰り返し / 開始想定 / 有効 / 操作** の順に並べる（2026-07-20 オーナー判断: 展開後にどう分類されるかを一覧で確認できるようにし、チェックボックスは属性を読んだ後に触る列として右端側へ寄せる）。

| 列 | 仕様 | 要求 |
|---|---|---|
| 名前 | テキスト。**モード色を名前の文字色に反映する**（S-01 と同じ表現。モード未設定は既定の文字色） | F-302 |
| モード | モード名を表示。未設定は空欄 | F-401 |
| プロジェクト | プロジェクト名を表示。未設定は空欄 | F-402 |
| 見積もり | `H:MM` | F-302 |
| 繰り返し | 人間可読の要約表示: 「毎日」「週次(月・水・金)」「月次(25日)」「3日ごと」。end_date設定時は「〜2026-09-30」を付記 | F-301 |
| 開始想定時刻 | `HH:MM`。時刻が属するセクション名を括弧で併記（導出表示） | F-302 |
| 有効トグル | チェックで `is_active` を即時切替。無効ルーチンは行をグレーアウト。**「開始想定」の右**に置く | F-303 |

- 並び順は開始想定時刻の昇順（同時刻は名前の自然順）＝展開後のデイリーリストと同じ並び。手動の並び替えは提供しない。フィルタ・検索は設けない（ルーチン数は数十件想定）

## 4. 編集フォーム（新規/編集共通）

モーダルまたはインライン展開フォーム。

| 項目 | 入力仕様 | 必須 |
|---|---|---|
| 名前 | テキスト | ○ |
| 見積もり | 分整数 | ○ |
| 繰り返し種別 | ラジオ: 毎日 / 週次 / 月次 / n日ごと | ○ |
| 曜日 | 週次のみ表示。曜日チェックボックス（複数可、1つ以上必須） | 週次時○ |
| 日 | 月次のみ表示。1〜31（月末超過は月末に丸める旨を注記） | 月次時○ |
| 間隔 | n日ごとのみ表示。正整数 | interval時○ |
| 開始想定時刻 | `HH:MM`。展開順とセクション配置の導出に使う | ○ |
| 開始日 | date。既定=今日。intervalの起算日を兼ねる | ○ |
| 終了日 | date。省略可（無期限） | |
| モード / プロジェクト | 各マスタからのセレクト。未設定可 | |

## 5. 操作仕様

| # | 操作 | 仕様 | 要求 |
|---|---|---|---|
| O-1 | 新規作成 | フォーム入力→保存。対象日（当日以降）を次に表示した時点で展開に反映される（データモデル定義書 §4.1）。開始日の既定は今日のため、当日のリストを開き直せば当日分も展開される。**今日からの展開が不要な場合は開始日を翌日に設定する** | F-301 |
| O-2 | 編集 | 保存後、未展開の日から反映。**展開済みタスクは変更されない**（要件定義書 §5.3） | F-302 |
| O-3 | 有効/無効 | 即時切替。無効化以後は展開されない。既存タスクは残る | F-303 |
| O-4 | 削除 | 確認ダイアログのうえ物理削除。展開済みタスクは `routine_id` を NULL にして残す（ログ保全） | F-303 |

- **その日だけ展開させたくない場合**は、S-01 で展開されたタスクを削除する。その日はスキップとして記録され再展開されない（F-304 / 画面定義書01 O-8）。ルーチン自体を無効化する必要はない
- 見積もりは1分以上を必須とする（0分は登録できない。S-01 のタスクは0分＝未設定を許容するが、ルーチンは繰り返し生成される雛形であり見積もりのないタスクを生み続けることになるため。2026-07-20 判断）
