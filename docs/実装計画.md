## 2. S-01 デイリーリスト

順序: 表示 → 追加・編集 → 打刻 → 並び替え → 中断・先送り・複製 → 終了予定時刻。

- [x] 1日分データ取得＋セクショングループ表示＋未分類（インボックス）＋日付ナビ（F-101/105/106）
- [x] クイック追加欄: 常設・名前のみ・連続追加（F-102, 画面定義書01 §3.4。楽観的更新で即時反映）
- [x] インライン編集: タスク名・見積もり（F-102/103）
- [x] ポップオーバー: モード / プロジェクト / セクション（O-5, キー M/P/S）
- [x] 打刻: 開始/終了トグル（Enter）＋割り込み処理を1トランザクションで（F-201）
- [x] 実行中タスクの経過リアルタイム表示・実績/見積差異の表示（F-202/205）
- [x] 開始・終了時刻のインライン修正（F-203, キー B/F、開始≦終了バリデーション。区切りなし入力にも対応）
- [x] 並び替え: ドラッグ＆ドロップ＋Shift+J/K（間隔採番、セクションまたぎで section_id 変更）
- [x] 中断（F-204）/ 先送り（F-107, 行メニューのみ）/ 複製（F-111, キー Y）/ 削除＋Undo（O-8, キー D/U）
- [x] 終了予定時刻・残時間の常時表示（F-104, 毎分＋操作都度再計算）＋セクション見積合計/過不足（F-110)
- [x] 選択行モデル＋全ショートカット＋ヘルプ（画面定義書01 §5/§6, キー C ジャンプ含む）
- [x] 前日以前の実行中タスク警告バナー（画面定義書01 §8。判定は「表示日より前」）
