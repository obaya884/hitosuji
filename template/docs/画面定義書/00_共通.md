# 画面定義書 00 共通

- 本書の責務: **全画面に共通する UI・操作**。個別画面の定義書（`01_*.md` 〜）は本書との差分だけを書く
- **UI が無いプロダクトならこのディレクトリを削除**し、`docs/README.md` の表からも行を消す

> 書き方: 画面ごとに `NN_画面名.md` を作る（NN は要件定義書 §4 の S-XX と揃える）。
> 各画面定義書のヘッダに「対応要求: F-XXX, …」の行を必ず置く（トレーサビリティ）。
> 操作は `O-X` で採番する。決定ログは `log_NN_画面名.md`（本書は `log_00_共通.md`）。

## 1. デザイン方針

> 全画面共通のトーン・レイアウト原則（例: 装飾を排したテーブル型リスト、モーダル最小限・インライン編集基本）。

## 2. 共通コンポーネント

> ヘッダ・ナビ・トースト・ポップオーバー等、複数画面で使う部品の仕様。

## 3. 共通の操作・キーボードショートカット

> ショートカットの設計方針（修飾キーの扱い等）と全画面共通のキー。画面固有のキーは各画面定義書に書き、**一覧としての正はどの文書か**をここで宣言する。

## 4. 決定ログ

共通 UI 判断の経緯は `log_00_共通.md` へ日付順に積む（最初のエントリが出た時点で作成。本節は参照スタブ）。
